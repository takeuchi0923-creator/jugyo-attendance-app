授業出欠管理 v3.8.4（画面整理版） GitHub Pages更新用

【更新方法】
1. ZIPをPCで展開します。
2. GitHubの takeuchi0923-creator / jugyo-attendance-app を開きます。
3. リポジトリ直下で Add file → Upload files を選びます。
4. 展開したフォルダ内の6ファイルをすべてアップロードします。
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
   - README_はじめに.txt
5. index.html など同名ファイルは置き換え（上書き）します。
6. Commit changes を押して確定します。
7. GitHub Pagesの反映後、PCで https://takeuchi0923-creator.github.io/jugyo-attendance-app/ を開いて確認します。

【重要】
・アップロードするのはアプリのプログラムとアイコン等のシステムファイルだけです。
・生徒名簿、出欠記録、バックアップJSON、パスワード、暗号鍵などの個人情報・データは絶対にGitHubへアップロードしないでください。
・既存ファイルを置き換える対象は上記5つのシステムファイルです。READMEは必要に応じて置き換えてください。
・アップロード前に、PC上でZIP内のindex.htmlを開いて画面と操作を確認してください。
・このZIPはGitHub更新用です。PCやiPad内の保存データを移動・削除するものではありません。
