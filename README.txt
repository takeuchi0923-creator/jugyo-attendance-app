授業出欠管理 v3.9.1（出欠変更・期間一括対応版）

GitHub Pages更新用のシステムファイル一式です。

含まれるファイル：
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

更新手順：
1. ZIPをPCで展開します。
2. GitHubリポジトリ jugyo-attendance-app のルートを開きます。
3. Add file → Upload files を選びます。
4. 展開した5ファイルをすべてアップロードします。
5. 同名ファイルを置き換え、Commit changes を実行します。

重要：ZIPファイル自体や、このパッケージに含まれない名簿・出欠記録・暗号化バックアップ・パスワード等はGitHubにアップロードしないでください。

Service Workerのキャッシュ名はv9に更新しています。GitHub Pages反映後、iPadではアプリをオンラインで開いて更新を待ってから利用してください。

このパッケージはシステムファイルのみです。個人データは含みません。
