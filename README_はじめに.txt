授業出欠管理 v3.8.9（バックアップ復元保護版）

このフォルダには、GitHub Pages等に配置する5つの必須ファイルが入っています。
- index.html
- sw.js
- manifest.webmanifest
- icon-192.png
- icon-512.png

重要：この版は検証用です。iPad33の実データに適用する前に、必ず別のテスト端末・テスト名簿で確認してください。
既存データの復元・上書き・GitHubへの公開は、このパッケージを確認しただけでは実施しないでください。

主な変更：
- 生徒の照合キーを「教科・クラス・番号」に統一。性別・氏名・ふりがな・端末ごとのID変更の影響を受けにくくする。
- 既存端末の生徒IDを維持し、別人へのID再利用は別IDに分離。
- 同一教科・クラス・番号の重複があれば名簿更新を中止。
- 名簿更新では出欠記録を変更しない。
- バックアップ復元時は書き込み後の照合を行い、失敗時には保存データとメモリ上の状態を元に戻す。
- Service Workerのキャッシュ名を更新。

注意：Service Workerを使うPWAの実運用にはHTTPS配信が必要です。index.htmlをPCで直接開く確認と、GitHub Pages上でのPWA確認は別です。

今回の修正：iPadなど幅1100px以下の画面で、授業日と単位数を横2列に配置し、入力欄が重ならないようにしました。

追加確認：バックアップのアプリバージョン表記をv3.8.9に統一しました。
